## 2. 目标与边界

研究局部生成式修复与整帧超分的执行顺序，建立可复核的画质与成本评价方法。以非露骨、可合法使用的样本和合成纹理开展实验；保管已有文件不等于将其纳入模型测试。

公开技术文档只使用匿名实验编号、相对路径、算法参数与硬件规格。素材来源映射、媒体指纹、机器连接信息与凭据只保存在不受版本控制的本地资料中。

## 4. 验收与检查点

1. T1 的媒体副本完整且不会进入 Git，公开文档无可识别来源信息。
2. T2 的实验可在 CPU 重复执行，数字与证据文件一致，结论准确限定为重采样行为。
3. T3 统一帧率、时序、分辨率、模型版本、画布与编码条件；分开记录质量控制实验和实际部署实验。
4. T4 同时考虑结构正确性、时序稳定性、区域接缝、非修复区域保真与资源消耗。缺少端到端证据时，不把候选方案写成实测最优。
5. 计划整体结项与归档由真实验收结果决定，不以局部实验通过替代。
